# BreatheWise
Machine Learning project for predicting Air Quality Index (AQI) using environmental data.


BreatheWise is a machine learning project focused on predicting Air Quality Index (AQI) using environmental and pollutant data.

## 🎯 Objective
To analyze air pollution patterns and build predictive models for AQI forecasting.

## 🛠 Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost

## 📊 Problem Type
- Regression (AQI prediction)
- Classification (Air Quality Category)
