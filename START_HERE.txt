================================================================================
AIR QUALITY ML PIPELINE - QUICK START GUIDE
================================================================================

STEP 1: Install Dependencies
-----------------------------
Open PowerShell in this folder and run:

    pip install pandas numpy scipy scikit-learn xgboost imbalanced-learn matplotlib seaborn joblib streamlit requests openpyxl python-dateutil

Wait for installation to complete (1-2 minutes).


STEP 2: Run the Pipeline
-------------------------
    python run_pipeline.py

This will:
- Analyze your data (EDA)
- Clean and preprocess
- Train 3 models (AQI, Gas, Health)
- Evaluate performance
- Save models to 'models/' folder

Time: 10-30 minutes depending on your computer


STEP 3: Launch Dashboard
-------------------------
After training completes:

    python run_dashboard.py

This opens a web dashboard at http://localhost:8501
Shows live predictions for all Egyptian governorates

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Import errors
Solution: Make sure you installed all dependencies (Step 1)

Problem: "Dataset not found"
Solution: Make sure clean_air_dataset.csv is in the root folder

Problem: Pipeline is slow
Solution: This is normal for 625,427 rows. Wait 10-30 minutes.

Problem: Dashboard won't start
Solution: Make sure you ran run_pipeline.py first to train models
